# StudentManagementSystem

A simple **Java Console-Based CRUD Application** that manages student records using an **ArrayList**.  
This project allows you to **Add, View, Update, Delete** student details using a menu-driven system.

---

## 📌 Features

- ➕ Add Student  
- 👁️ View All Students  
- ✏️ Update Student Details  
- ❌ Delete Student  
- 💾 Stores data temporarily using ArrayList  
- 🧱 Uses OOP (Classes & Objects)

## ▶ How to Run the Program

1. Open the project in **Eclipse / IntelliJ / VS Code**  
2. Open the file:  
   ```
   Main.java
   ```
3. Run the program:
   ```
   Run As → Java Application
   ```
4. The menu will appear in your console:
   - 1 → Add Student  
   - 2 → View Students  
   - 3 → Update Student  
   - 4 → Delete Student  
   - 5 → Exit
